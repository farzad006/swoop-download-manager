## Swoop 1.0.14

### ⬇️ Download

**[Swoop-Setup-x64.exe](https://github.com/farzad006/swoop-download-manager/releases/download/v1.0.14/Swoop-Setup-x64.exe)** for Windows 10/11. Install it over your current version; your downloads and settings are kept.

> Swoop isn't code-signed yet, so Edge may say *"isn't commonly downloaded"* (click **⋯ → Keep → Show more → Keep anyway**) and Windows may say *"Windows protected your PC"* (click **More info → Run anyway**).

### 🐛 Fixed

- **"server returned HTTP 472" and other expired video links.** Video sites sign their file links for a few hours, and a tab left open overnight still hands over its old link. When such a link has expired, Swoop now gets a fresh one from the video's page and downloads in the same quality. Downloads that already failed this way work again with **Try again**.
