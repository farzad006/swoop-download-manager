## Swoop 1.0.4

### ⬇️ Download

**[Swoop-Setup-x64.exe](https://github.com/farzad006/swoop-download-manager/releases/download/v1.0.4/Swoop-Setup-x64.exe)** for Windows 10/11. Install it over your current version; your downloads and settings are kept.

> Swoop isn't code-signed yet, so Edge may say *"isn't commonly downloaded"* (click **⋯ → Keep → Show more → Keep anyway**) and Windows may say *"Windows protected your PC"* (click **More info → Run anyway**).

### 🐛 Fixed

- **"Swoop couldn't read this video" with `SSL: UNEXPECTED_EOF_WHILE_READING`.** Some sites' IPv6 servers cut off a share of connections, especially over VPNs such as Cloudflare WARP. Browsers hide this by retrying; the video downloader didn't. Swoop now retries dropped connections automatically (up to 3 attempts, over IPv4) and remembers sites that need IPv4, so they work first time afterwards. If a connection really can't be made, you get a plain explanation instead of the technical error.
