## Swoop 1.0.5

### ⬇️ Download

**[Swoop-Setup-x64.exe](https://github.com/farzad006/swoop-download-manager/releases/download/v1.0.5/Swoop-Setup-x64.exe)** for Windows 10/11. Install it over your current version; your downloads and settings are kept.

> Swoop isn't code-signed yet, so Edge may say *"isn't commonly downloaded"* (click **⋯ → Keep → Show more → Keep anyway**) and Windows may say *"Windows protected your PC"* (click **More info → Run anyway**).

### 🐛 Fixed

- **YouTube: "Requested format is not available".** When you're signed in to YouTube, it asks the downloader to solve a JavaScript challenge first; if it can't, only thumbnails are offered and the download fails. Swoop now:
  - retries once without your browser cookies when a site offers nothing downloadable, which works for normal public videos;
  - installs yt-dlp's challenge solver (`yt-dlp-ejs`) during its daily yt-dlp update, if you installed yt-dlp with pip.

  If you installed yt-dlp with winget, also run `winget install DenoLand.Deno` so challenges can be solved.
