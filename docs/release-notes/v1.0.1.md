## Swoop 1.0.1

### ⬇️ Download

**[Swoop-Setup-x64.exe](https://github.com/farzad006/swoop-download-manager/releases/download/v1.0.1/Swoop-Setup-x64.exe)** for Windows 10/11. Install it over 1.0.0; your downloads and settings are kept.

> Swoop isn't code-signed yet, so Edge may say *"isn't commonly downloaded"* (click **⋯ → Keep → Show more → Keep anyway**) and Windows may say *"Windows protected your PC"* (click **More info → Run anyway**).

### 🐛 Fixed

- **"Connect your browsers" opened as an empty white window** when started from the sidebar or Settings. It now opens properly.

### 🔧 Behind the scenes

- Installers are now built and published automatically by GitHub Actions from the public source code, with SHA-256 checksums for every file.
