## Swoop 1.0.6

### ⬇️ Download

**[Swoop-Setup-x64.exe](https://github.com/farzad006/swoop-download-manager/releases/download/v1.0.6/Swoop-Setup-x64.exe)** for Windows 10/11. Install it over your current version; your downloads and settings are kept.

> Swoop isn't code-signed yet, so Edge may say *"isn't commonly downloaded"* (click **⋯ → Keep → Show more → Keep anyway**) and Windows may say *"Windows protected your PC"* (click **More info → Run anyway**).

> After installing, reload the Swoop extension once (Extensions page → Swoop → reload) to get the faster video button.

### ⚡ Faster

- **"Download this video" opens the quality list almost instantly.** Swoop now looks a video up as soon as it appears on the page, instead of when you first hover over it. It also keeps a window ready, so the dialog no longer waits about a second for Windows to build one. In testing, the list appeared 0.25 s after the click instead of 4.3 s.
- On YouTube, moving to another video now looks the new one up too.

### 🐛 Fixed

- **Downloads that looked stuck at 95–100% although the file was finished.** A quick download could finish while its progress window was still opening, and the window missed the "done" message. A late progress update could also make a finished download look like it was still running in the main list. The list now always follows a download's real state, and the progress window checks again if it ever misses an update.
