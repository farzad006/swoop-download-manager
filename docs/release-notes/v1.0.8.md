## Swoop 1.0.8

### ⬇️ Download

**[Swoop-Setup-x64.exe](https://github.com/farzad006/swoop-download-manager/releases/download/v1.0.8/Swoop-Setup-x64.exe)** for Windows 10/11. Install it over your current version; your downloads and settings are kept.

> Swoop isn't code-signed yet, so Edge may say *"isn't commonly downloaded"* (click **⋯ → Keep → Show more → Keep anyway**) and Windows may say *"Windows protected your PC"* (click **More info → Run anyway**).

### 🐛 Fixed

- **Video downloads failing with `ModuleNotFoundError: No module named 'yt_dlp'`.** If an update of the video downloader (yt-dlp) is cut off halfway, for example by shutting down the PC, pip leaves it broken. Swoop now notices this, reinstalls yt-dlp by itself and carries on with the download. After each daily update it also checks that yt-dlp still works.
- **The daily yt-dlp update ran every time Swoop started**, not once a day, which made an interrupted update much more likely. It now really runs at most once a day.
- yt-dlp installed in a Python virtual environment can now be updated and repaired too.
