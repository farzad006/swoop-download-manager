## Swoop 1.0.3

### ⬇️ Download

**[Swoop-Setup-x64.exe](https://github.com/farzad006/swoop-download-manager/releases/download/v1.0.3/Swoop-Setup-x64.exe)** for Windows 10/11. Install it over your current version; your downloads and settings are kept.

> Swoop isn't code-signed yet, so Edge may say *"isn't commonly downloaded"* (click **⋯ → Keep → Show more → Keep anyway**) and Windows may say *"Windows protected your PC"* (click **More info → Run anyway**).

### 🐛 Fixed

- **Downloading a video with the same name again** (for example a second `abc.mp4`) seemed to start but saved nothing, because the existing file made the download get skipped. Swoop now saves it as **`abc (1).mp4`**, then `abc (2).mp4`, and so on, the same way regular downloads already were. Existing files are never overwritten.
