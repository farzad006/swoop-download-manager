## Swoop 1.0.19

### ⬇️ Download

**[Swoop-Setup-x64.exe](https://github.com/farzad006/swoop-download-manager/releases/download/v1.0.19/Swoop-Setup-x64.exe)** for Windows 10/11. Install it over your current version; your downloads and settings are kept.

> Swoop isn't code-signed yet, so Edge may say *"isn't commonly downloaded"* (click **⋯ → Keep → Show more → Keep anyway**) and Windows may say *"Windows protected your PC"* (click **More info → Run anyway**).

### ⚡ Faster

- **"Looking at the video…" no longer spins for minutes.** Swoop now reads the page and the stream your browser is playing at the same time, so a page it can't read costs no extra wait. Each lookup is stopped after 40 seconds, and dropped connections are only retried for 30 seconds.

### 🐛 Fixed

- **Video servers that answer "403 Forbidden".** Some servers only accept connections that look like a browser's. When a lookup or download is refused, Swoop tries again connecting the way Chrome does, and remembers that server.
- **"disk error: The system cannot find the file specified".** Two downloads with the same name (two videos both called `video.mp4`) wrote the same temporary file. The second one now gets a numbered name.
- **"HTTP 404" partway through a big download.** Some sites' links only work for an hour or two. When a link dies, Swoop looks on the page it came from for the same file's new address and carries on.
- **A search-results page could keep a background lookup busy for minutes**, which slowed down every lookup after it.
