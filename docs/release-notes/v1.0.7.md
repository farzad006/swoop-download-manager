## Swoop 1.0.7

### ⬇️ Download

**[Swoop-Setup-x64.exe](https://github.com/farzad006/swoop-download-manager/releases/download/v1.0.7/Swoop-Setup-x64.exe)** for Windows 10/11. Install it over your current version; your downloads and settings are kept.

> Swoop isn't code-signed yet, so Edge may say *"isn't commonly downloaded"* (click **⋯ → Keep → Show more → Keep anyway**) and Windows may say *"Windows protected your PC"* (click **More info → Run anyway**).

### ✨ New

- **"Download complete" notification with buttons.** When a download finishes, the Windows notification now has **Open** and **Show in folder** buttons; clicking the notification itself brings up Swoop. If you'd rather not have a window pop up for every download, turn off **Settings → General → Show a progress window** and **"Download complete" window**. The notification gives you the same shortcuts.
